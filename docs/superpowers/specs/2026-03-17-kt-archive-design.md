## 1. Цель и границы блока 1

**Цель блока 1:** поднять фундамент проекта — репозиторий, окружение, базовую архитектуру, аутентификацию, роли, дерево категорий и минимальные CRUD‑экраны без визуальной полировки.  
**Всё последующее (контентные модули, медиа, админка, бэкапы, полный дизайн) — в блоках 2–3.**

## 2. Ключевые решения

- **Стек:** Next.js 15 (App Router), TypeScript, Prisma + PostgreSQL, Auth.js v5 (Credentials), TanStack Query, shadcn/ui (стиль `new-york`).
- **Доступ:** только по логину/паролю; даже `GUEST` проходит через `/login`.
- **Хранение медиа:** локально в проекте (`uploads/`), путь через `UPLOADS_DIR` в env для лёгкого переноса на VPS.
- **Локальная БД:** `docker-compose` с Postgres.
- **UI:** минимальные рабочие экраны (функционально, без дизайн‑полировки).

## 3. Архитектура и структура

**Слои:**
- `app/` — страницы + API роуты.
- `components/` — UI и функциональные компоненты.
- `lib/` — auth/prisma/search/sharp/ffmpeg/disk.
- `hooks/` — TanStack Query хуки.
- `prisma/` — схема и seed.
- `tests/` — unit/integration/e2e.

**Роли и доступ:**
- Middleware защищает все маршруты, кроме `/login`.
- Роль `ADMIN` — доступ к `/admin`.
- Роль `GUEST` — запрет на редактирование/создание (проверяется и в UI, и на сервере).

## 4. Компоненты и потоки данных (минимальный UI)

**Страницы:**
- `/login` — вход по credentials.
- `/dashboard` — простая стартовая страница.
- `/section/[categoryId]` — список патологий в категории.

**Навигация:**
- `Sidebar` с деревом категорий (`GET /api/categories`).

**CRUD в блоке 1:**
- Категории: `GET/POST/DELETE` (с запретом удаления `isLocked=true`).
- Патологии: `GET/POST/PUT/DELETE` (минимальная форма).
- Протоколы: `GET/POST/PUT/DELETE` (минимальная форма).

**Клиентский стейт:**
- TanStack Query: `["categories"]`, `["pathologies", categoryId]`, `["protocols"]`.
- Инвалидация после мутаций.

## 5. Ошибки и безопасность

**Формат ошибок API:** `{ error: string, code: string }`

**Ключевые случаи:**
- 401: редирект на `/login`.
- 403: тост “Недостаточно прав”.
- 400 при удалении `isLocked`: тост “Системная папка не может быть удалена”.
- 500: общий тост “Что-то пошло не так”.

**Важно:** все критические проверки ролей дублируются в API‑роутах.
