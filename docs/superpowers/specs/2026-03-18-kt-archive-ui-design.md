## 1. Цель

Финальная визуальная полировка внешней части приложения после готовности всей внутрянки.  
Стиль: **Tech Grid** + **balanced плотность**.  
Фокус: читаемость медицинского контента и скорость повседневной работы.

## 2. Визуальная система

### 2.1 Типографика
- Основной шрифт: **IBM Plex Sans** (заголовки и текст).
- Иерархия:
  - H1: 28–30px / 600–700
  - H2: 22–24px / 600
  - H3: 18–20px / 600
  - Body: 14–16px / 400–500
  - Caption: 12px / 400

### 2.2 Палитра (Mint)
- Основной акцент: `#0F766E`
- Светлый акцент: `#CCFBF1`
- Фон: `#F6FBF9`
- Карточки: `#FFFFFF`
- Обводки: `#D5EEE7`
- Текст основной: `#0F172A`
- Текст вторичный: `#486B5D`
- Ошибка: `#DC2626`
- Предупреждение: `#D97706`
- Успех: `#16A34A`

### 2.3 Компоновка и плотность
- Сетка 8px.
- Плотность **balanced**: средние отступы, без «пустоты», но читабельно.
- Радиусы:
  - Кнопки: 10–12px (мягкие)
  - Карточки: 12–14px
  - Инпуты: 10–12px

### 2.4 Фон и атмосфера
- Фон не плоский: мягкий градиент mint‑оттенка + лёгкий шум/паттерн.
- Главное правило: фон не отвлекает от контента.

### 2.5 Состояния и интеракции
- Hover: лёгкое усиление обводки и тени.
- Focus: видимый кольцевой фокус (mint‑accent).
- Disabled: снижен контраст + прозрачность 40–60%.

### 2.6 Анимации
- Небольшой fade/slide при появлении секций.
- Списки — лёгкий stagger (100–150ms).
- Без тяжёлых анимаций.

## 3. Основной макет

### 3.1 Навигация
- **Классический сайдбар** слева с деревом категорий.
- Верхняя полоса (header) с быстрым поиском и контекстом.

### 3.2 Контентная зона
- Основные карточки справа от сайдбара.
- Карточка = контейнер для контента и блоков (TODO, Комментарии, Медиа).

## 4. Экранные сценарии

### 4.1 Логин
- Центрированный блок.
- Акцентная кнопка входа.
- Минимум лишнего текста.

### 4.2 Дашборд
- Краткая стартовая информация.
- Быстрый доступ к разделам.

### 4.3 Категория → список патологий
- Карточки патологий.
- Внутри карточки: заголовок, краткий контент, блоки TODO/Комментарии/Медиа.

### 4.4 Поиск
- Строка поиска сверху.
- Два списка результатов: патологии и протоколы.

### 4.5 Протокол
- Отдельная страница с контентом + медиа.

## 5. Компоненты

- **Card:** ключевой контейнер.
- **Button:** soft‑style, primary/secondary.
- **Input:** мягкий радиус, тонкая обводка.
- **Badge:** лёгкие ярлыки для статусов.
- **Sidebar items:** hover‑подсветка mint.

## 6. Не‑цели

- Редизайн UX‑логики.
- Изменение бизнес‑логики или API.
